## Failure patterns → reinforcement shipped (this branch, pre-merge)

1. **Mode 2 had no selection fallback when search pages are blocked** (5/5 walks improvised proxies). → SKILL.md mode-2 rules: substitute the closest marketplace-authored ranked surface, label it, or request a search screenshot.
2. **Marketplace fetchability was undocumented.** → every marketplaces/*.md gained a "Mode-2 fetchability (observed 2026-07-26)" section, including eBay's browser-UA path into embedded JSON and TikTok's server-rendered `/us/k/` grids (discovered by the eval).
3. **200-but-shell responses** (Amazon dp pages) were neither block nor content. → named in SKILL.md mode-2 rules and amazon.md.
4. **Lean-back was fictive without a screen.** → mode-2 passes redefined as data-level, with the inferred-from-data disclosure required.
5. **Template contradiction:** exhibits mandated unconditionally vs. impossible in modes 2–3. → exhibits index scoped to live-browser walks; evidence rules for other modes.
6. **`latest.json` version check failed 5/5** — Cloudflare bot-shields jeremyperonto.com against fetch tools; the skill skipped silently as designed but the notifier was effectively dead for fetch-tool users. → manifest now also written to the repo root and the skill fetches the raw.githubusercontent URL instead.
7. **Protocol fixes:** agent read lists must include measurement.md (2/5 agents flagged the gap; 2 others self-recovered); browser-UA fetches count as mode-2 tools; per-platform internal metrics extended to eBay, Etsy, Walmart, TikTok Shop in measurement.md.

Also observed, no action: "Sources verified" dates equal to the eval date left the freshness rule untested — it first becomes testable ~90 days after this release. Minor report-format variance (The-short-version section trimmed under the line cap by 3/5 agents) — accepted; the cap caused it.

## Verdict

**Pass.** v1.3.0 ships with the seven reinforcement changes above. The eval protocol did its job on its first run: two genuine capability discoveries (eBay embedded JSON, TikTok SEO grids), one infrastructure bug caught before users hit it, and a mode-2 rule set the skill lacked.
